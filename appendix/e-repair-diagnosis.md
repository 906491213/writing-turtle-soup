# 修缮诊断：修，还是重熬？

**何时使用**：任一成品闸门、解题链卡或盲测不通过时。它不是可选灵感库；它决定回哪一步，以及修后必须重跑什么。

## 先判根：两个故事还能各自站住吗？

遮住故事甲，只读故事乙；再遮住故事乙，只读故事甲。

- 两边都有自己的角色、因果和结局，只是在交叉点重合 → **可修缮**。
- 任一边只是另一边的逐句翻译、设定注释或手法说明 → **重熬该故事**，回创作步骤 3。

不要在一具没有独立生命的故事上补线索；那只会把汤面写成说明书。

## 失败分类与决策

| 失败信号 | 问题本质 | 修缮条件 | 否则 |
|---|---|---|---|
| 承重事实三种触发源全空 | 不可达 | 能在不泄底的前提下补题内锚点，或由上一拍自然推出 | 重熬交叉点或故事乙 |
| 发现后没有有效下一问 | 不可导航 | 能重写本拍答案，使其授予新方向/工具 | 重构拍间关系 |
| 机制猜想没有区分性检验 | 不可证实 | 能加入玩家可执行、可预期不同结果的检验 | 重熬机制 |
| 盲测前几问命中核心 | 距离不足 | 核心仍在清单外，只是接缝或烟雾弹泄露 | 重熬交叉点/加密公理 |
| 多个标准问题直接命中 | 核心落在标准清单内 | 单点泄露可换措辞或换表层身份 | 重熬核心公理 |
| 双读左列为空 | 无辜故事不存在 | 极少数句子可删或改为真双读 | 重熬故事甲或交叉点 |
| 双读左列指向真相 | 汤面泄底 | 可换叙述焦点、时机或动词 | 重写汤面并复验 |
| 需要越界扶车才推进 | 题内因果缺失 | 提示能改为指向已有锚点 | 回步骤 4/5 补链；不能则重熬 |

### 三个高危信号

**名词/动词诊断**：交叉点若是“拆迁、封印、替身、镜像”等概念名词，而非可观察行为，先回步骤 4。玩家不能从一个标签推导标签。

**小说写作冲动检测**：每句新增文字都问三件事：无辜读法是否自然？它是否改变发现链或双读？它是否引入题外知识？三问有任一否，删掉或回到因果骨架。

**一句压测**：若核心可被一句常规猜测完整说出，检查是否伪多层、接缝距离过短，或只是把设定拆成了多段。

## 修后最小复跑：按语义影响，不按改了几行字

| 改动改变了什么 | 至少重跑 |
|---|---|
| 仅文风，锚点/无辜读法/事实均不变 | 修改句的双读审计 |
| 无辜读法、锚点或烟雾弹 | 该句双读 + 接缝 + 对应解题链行 + 模拟问答 |
| 一拍答案、最小确认集合或下一拍入口 | 该拍及后续解题链 + 长汤接力（如适用）+ 模拟问答 |
| 状态迁移、回答协议或校验方法 | 状态协议 + 可证实性审计 + 主持桌面走读 |
| 交叉点、故事甲/乙或核心机制 | 从步骤 3 起全跑；含盲测与标准清单 |

## 执行顺序

```text
失败记录 → 判两个故事是否独立
  → 不独立：重熬步骤 3
  → 独立：按失败分类决定补锚点、重接力、重机制或重措辞
    → 按语义影响重跑最小集
      → 仍失败：扩大到上一级改动；不要继续堆补丁
```
