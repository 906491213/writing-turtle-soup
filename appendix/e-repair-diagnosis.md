# 修缮诊断：修，还是重熬？

**位置**：四阶段总线——修复或回炉阶段。复验报告判定"修复"或"回炉"后，在此完成故障归因与最小复跑规划。

**何时使用**：任一成品闸门、解题链卡或盲测不通过时；或用户实际游玩后提交观察记录时。它不是可选灵感库；它决定回哪一步，以及修后必须重跑什么。

---

## 零、用户观察记录模板（反馈驱动入口）

用户实际开汤后，用以下格式提交观察。AI 据此做故障归因，而非凭复验报告猜测。

```
【观察记录】〔汤名〕  版本号：______  主持日期：______

一、现象
  描述你观察到的问题（玩家卡在哪里、哪个回答让玩家困惑、哪个方向玩家根本没碰）：

二、位置
  问题发生在第几拍/哪个变量/哪句汤面/哪个回答：

三、影响
  对游戏体验的实际影响（玩家放弃、预算耗尽、主持人被迫越界扶车）：

四、已尝试问题
  玩家问了哪些正确问题但没得到有效方向？主持人尝试了哪种扶车（轻/中/重）？
```

---

## 一、先判根：P 和 T 是否各自自洽？

遮住表层模型 P（汤面），只读深层模型 T（汤底）；再遮住 T，只读 P。

- P 在载体自洽（表层可独立阅读或使用）、T 完整可独立理解（因果说明/文档解释/拼图复原/规则模型）→ **可修缮**。
- 任一边只是另一边的逐句翻译、设定注释或手法说明 → **重熬该模型**，回制汤步骤2（按载体构建P和T）。

不要在一具没有独立生命的模型上补线索；那只会把汤面写成说明书。

## 二、失效层映射（反馈→归因）

将用户观察记录中的现象映射到失效层，确定回退入口。

| 失效层 | 判定问 | 典型症状 | 回退入口 |
|---|---|---|---|
| **胚** | 原子双读是否仍然成立？第二框架/移除测试是否仍然通过？ | 玩家方向与汤底方向根本无交集；汤面无辜读法不自然 | 回立项闸门1或2 |
| **P/T** | P是否自洽可读？T是否遮住P仍独立成立？ | P只是T的逐句翻译；T离开P无法理解 | 回制汤步骤2重建P或T |
| **约束点** | 行为交叉/感官错配/格式异常/碎片关系/现象规则映射是否仍然成立？ | 玩家找不到从汤面进入推理的入口 | 回制汤步骤4（约束点定位） |
| **变量足迹** | 最终变量集的每个变量是否通过L1+L2？独立证据族是否满足？ | 玩家无法发现某类变量；知道答案后回溯发现"题内没线索" | 回制汤足迹预检补锚点或证据族 |
| **解题导航** | 每拍是否有≥2个自然方向？确认门是否完整？推理落脚点是否成立？ | 玩家确认一事后不知道下一步该问什么；只能靠主持人提示方向 | 回制汤解题链卡补方向或确认门 |
| **主持协议** | 回答协议是否可执行？危险问题预设是否充足？状态迁移是否可监控？ | 主持人频繁感到"这个问题不能诚实回答"；状态迁移信号未被玩家识别 | 回制汤步骤11或状态协议卡 |
| **表达** | 措辞是否产生无辜/汤底双读？锚点是否因措辞被埋没？ | 特定句子被玩家反复误解；锚点措辞过于隐晦 | 回制汤步骤8（汤面措辞） |

## 三、失败分类与决策

| 失败信号 | 问题本质 | 修缮条件 | 否则 |
|---|---|---|---|
| 承重事实三种触发源全空 | 不可达 | 能在不泄底的前提下补题内锚点，或由上一拍自然推出 | 重熬约束点或深层模型T |
| 发现后没有有效下一问 | 不可导航 | 能重写本拍答案，使其授予新方向/工具 | 重构拍间关系 |
| 机制猜想没有区分性检验 | 不可证实 | 能加入玩家可执行、可预期不同结果的检验 | 重熬机制 |
| 盲测前几问命中核心 | 距离不足 | 核心仍在清单外，只是接缝或烟雾弹泄露 | 重熬约束点/加密公理 |
| 多个标准问题直接命中 | 核心落在标准清单内 | 单点泄露可换措辞或换表层身份 | 重熬核心公理 |
| 双读左列为空（A类） | 无辜解释不存在 | 极少数句子可删或改为真双读 | 重熬表层模型P或约束点 |
| 双读左列指向真相（A类） | 汤面泄底 | 可换叙述焦点、时机或动词 | 重写汤面并复验 |
| 碎片关系无信息差（D类） | 拼图不承载推理 | 加强碎片间矛盾或对应 | 重熬碎片关系设计 |
| 需要越界扶车才推进 | 题内因果缺失 | 提示能改为指向已有锚点 | 回制汤解题链卡或足迹预检补链；不能则重熬 |
| 隐藏变量无足迹（L1失败） | 变量在汤面无反事实痕迹 | 能在不泄底的前提下补题内锚点，或由上一拍自然推出 | 回制汤足迹预检补锚点或降级为纹理 |
| 有足迹但不区分（L2失败） | 足迹指向多个竞争解释 | 能补第二个独立证据族排除关键替代解释 | 回制汤足迹预检补独立证据族 |
| 关系/事件/规则变量独立证据族<2 | 区分性不足 | 能补独立来源或渠道的证据族 | 回制汤足迹预检或约束点 |

### 三个高危信号

**名词/动词诊断**：交叉点若是”拆迁、封印、替身、镜像”等概念名词，而非可观察行为，先回制汤步骤4（约束点定位）。玩家不能从一个标签推导标签。

**小说写作冲动检测**：每句新增文字都问三件事：无辜读法是否自然？它是否改变发现链或双读？它是否引入题外知识？三问有任一否，删掉或回到因果骨架。

**一句压测**：若核心可被一句常规猜测完整说出，检查是否伪多层、接缝距离过短，或只是把设定拆成了多段。

## 修后最小复跑：按语义影响，不按改了几行字

| 改动改变了什么 | 至少重跑 |
|---|---|
| 仅文风，锚点/无辜读法/事实均不变 | 修改句的双读审计 |
| 无辜读法、锚点或烟雾弹 | 该句双读 + 接缝 + 对应解题链行 + 模拟问答 |
| 一拍答案、最小确认集合或下一拍入口 | 该拍及后续解题链 + 长汤接力（如适用）+ 模拟问答 |
| 状态迁移、回答协议或校验方法 | 状态协议 + 可证实性审计 + 主持桌面走读 |
| 隐藏变量清单/足迹/证据族 | 从制汤足迹预检起全跑；含反事实足迹三层测试 + 独立证据族验证 |
| 约束点、表层模型P/深层模型T或核心机制 | 从制汤步骤2起全跑；含盲测与标准清单 |

## 执行顺序

```text
失败记录 → 判P和T是否各自自洽
  → 不独立：重熬制汤步骤2
  → 自洽：按失败分类决定补锚点、重接力、重机制或重措辞
    → 按语义影响重跑最小集
      → 仍失败：扩大到上一级改动；不要继续堆补丁
```
