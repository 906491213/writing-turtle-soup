# 附录D：难度构造与定级

**位置**：动笔前选难度构造蓝图；成汤后实测对照。本附录是**施工规格**，不是事后评分表。

**级别**：主线——填委托卡时必查，盲测后必对照。

**核心原则**：难度不是测出来的，是构造出来的。先选难度 → 按蓝图搭 P/T/锚点/解题链 → 盲测验证蓝图是否落实。

**铁律**：难度构造参数（F1-F4）是制汤阶段的施工规格，不得作为胚资格不通过的补偿。胚在立项阶段因锚点稀疏、推理断层等原因未通过闸门时，不能通过"降一档难度"来放行——胚资格是结构问题，难度是体验设计问题，二者不可互相抵消。

---

## 命名体系

### 载体代码（仅指汤型，不表难度）

```
A · 事件汤     B · 感官汤     C · 文档汤     D · 拼图汤     E · 机制汤
```

### 难度档位（废弃字母等级）

| 档位 | 名称 | 简称 |
|---|---|---|
| 1 | **热场** | 新人入门，接缝一击即中，1次信念更新 |
| 2 | **常规** | 日常开汤，路径短且直 |
| 3 | **标准** | 有竞争框架或翻转，但全程可导航 |
| 4 | **进阶** | 接缝隐蔽或翻转幅度大，需多轮排除 |
| 5 | **深度** | 推理链深、竞争框架多、翻转幅度大 |

### 消歧规则

- `B·感官汤` = 载体类型。`B级汤` = 歧义，必须追问。
- 委托卡和输出模板中，载体和难度**始终分两行标注**。
- 单独的 "C级汤""D级汤" 一律判为废弃写法。

## 第一层：质量闸门（所有载体共用，Pass/Fail）

**不通过 → 回炉，不定级。** 所有难度档都必须通过质量闸门——热场汤也不能有断层，深度汤靠更多信念更新和更强竞争框架，不是靠砍锚点来制造难度。

| 闸门 | 检查内容 | 对应旧闸门 |
|---|---|---|
| **G-锚点** | 按变量类型分层审计（见下方），不搞一刀切 | G1c + G11独立证据族 |
| **G-导航** | 每拍答案有 ≥1 个汤面可追溯锚点引导；路径无断层 | G10推理落脚点 |
| **G-确认门** | 每个关键分叉有 ≥1 个"无论答案都能收窄搜索空间"的问题 | 新增强制检查 |
| **G-竞争解释** | 全部核心变量合并后，不存在一个完整、具体、与全体事实相容的竞争汤底 | G11竞争解释排除 |

### 锚点审计（按变量类型分层）

| 变量类型 | 最低锚点要求 |
|---|---|
| 简单物理变量（发生了什么物理事件） | 1条明确锚点 + 1个可触及的确认门 |
| 简单身份变量（X是谁/曾是谁） | 1条明确锚点 + 1个可触及的确认门 |
| 关系变量（X和Y之间发生过什么） | 2条独立证据族，至少1条能排除关键替代解 |
| 事件变量（某件事的真实过程与记录不同） | 2条独立证据族，至少1条能排除关键替代解 |
| 规则变量（世界按什么隐藏规律运作） | 2条独立证据族 + 至少1条是预测/反例型 |

热场汤不会被"每个变量都要2条独立证据"逼成多线索堆料——简单物理和身份变量只需1锚点+1确认门。

### 竞争解释审计（限定范围）

> 对每个承重变量，列出至少2个最强的竞争解释。它们必须各自被汤面或已确认事实中的具体证据排除。全部核心变量合并后，不得存在一个完整、具体、与全体事实相容的竞争汤底。

审计范围限定为最强的2个竞争解释，不要求穷尽所有可能。

## 第二层A：难度构造参数 F1-F4（所有载体共用）

这些参数在委托卡阶段作为**施工规格**填写，成汤后通过盲测验证。

### F1 · 入口埋深

接缝从汤面中被定位的难度，以及从接缝抵达第一个正确方向的轮次。

| 分 | 锚点描述 | 构造参数 |
|---|---|---|
| 1 | 接缝一击即中 | 核心异常放在汤面前1/3位置；前3问内自然触及 |
| 2 | 偏浅 | 1分和3分之间的明确中间状态 |
| 3 | 接缝可见但被分流 | 核心异常与1-2个次要异常并存；前5问内正确方向不优先 |
| 4 | 偏深 | 3分和5分之间的明确中间状态 |
| 5 | 接缝深埋 | 核心异常被日常细节包裹；前10问大概率在错误方向消耗；需排除1-2个错误方向后才能发现正确入口 |

**盲测量化**（≥3次独立盲测的中位数）：
- 1分：进入正确方向轮次中位数 ≤3
- 3分：中位数 6-10
- 5分：中位数 ≥15

### F2 · 链条深度

不可互相归约的独立信念更新次数。同一核心翻转的递进展开不计为多次。

| 分 | 锚点描述 | 构造参数 |
|---|---|---|
| 1 | 1次信念更新 | 单拍，从表层到真相只需一次框架替换 |
| 2 | 偏浅 | 1分和3分之间的明确中间状态 |
| 3 | 2-3次独立信念更新 | 2拍，每次更新不可被前一次归约；每次更新有独立确认门 |
| 4 | 偏深 | 3分和5分之间的明确中间状态 |
| 5 | 5+次独立信念更新，或含元层翻转 | 3+拍；元层翻转（翻转本身被再次翻转）仅在构成独立信念更新时计入，不免费加分 |

### F3 · 竞争阻力

可与真相竞争、且能承受多轮追问而不崩解的错误框架数量与寿命。

| 分 | 锚点描述 | 构造参数 |
|---|---|---|
| 1 | 无自然竞争框架 | 真相是唯一能解释全部事实的模型 |
| 2 | 偏弱 | 1分和3分之间的明确中间状态 |
| 3 | 1个有效竞争框架 | 可承受5-8轮诚实追问而不崩解；需确证才能排除 |
| 4 | 偏强 | 3分和5分之间的明确中间状态 |
| 5 | 2+个有效竞争框架，且至少一个部分正确 | 存在"半对半错"的竞争框架——与真相共享大量事实，排除它需要区分微妙边界 |

**盲测量化**（≥3次独立盲测的中位数）：
- 有效竞争框架数 + 各自从建立到排除的中位轮次
- 1分：0个或1个弱框架（寿命≤3轮）
- 3分：1个框架，寿命5-8轮
- 5分：2+个框架，至少1个寿命≥10轮

### F4 · 翻转幅度

从表层模型P到深层模型T所需的框架替换幅度。

| 分 | 锚点描述 | 构造参数 |
|---|---|---|
| 1 | 延伸型 | T是P的自然延伸，只补充P中缺失的因果链 |
| 2 | 偏浅 | 1分和3分之间的明确中间状态 |
| 3 | 反转型 | T颠倒了P中一组核心关系（如债权人与债务人身份互换） |
| 4 | 偏深 | 3分和5分之间的明确中间状态 |
| 5 | 颠覆型 | T推翻了P的基本前提（如"这不是犯罪现场"→"这根本不存在"），且中途建立的中间框架也被推翻 |

## 第二层B：载体专属审计层（不参与难度加分）

载体不靠固定加分影响难度。载体只决定**如何验证这锅汤的结构是否公平**。

### A·事件汤

| # | 检查项 | 通过条件 |
|---|---|---|
| A1 | 因果重释独立性 | 表层和深层因果链各自独立成立，不是"先写汤底再穿汤面衣服" |
| A2 | 行为交叉点 | 同一可观察行为在P和T中有不同的因果前件，汤面完整呈现了该行为 |
| A3 | 表层自洽 | 表层因果解释自洽，不依赖缺失动机或未声明的外部事实维持成立 |

### B·感官汤

| # | 检查项 | 通过条件 |
|---|---|---|
| B1 | 信号物理可混淆 | 汤面明确描述感官信号+接收条件，两种物理来源在此条件下无法区分 |
| B2 | 信号可区分 | 存在汤面内可见的辨别方法（追问可触及），诚实回答能使信号来源唯一化 |
| B3 | 来源非魔法 | 微变格/变格汤也需解释信号的物理产生机制 |

### C·文档汤

| # | 检查项 | 通过条件 |
|---|---|---|
| C1 | 格式异常可逆推 | 文档的格式/结构/署名/时间异常可指向真实作者、写作动机或记录条件 |
| C2 | 非逐句隐喻翻译 | 不是"每句话对应一个隐藏含义"的映射表；先有异常结构，后有解释 |
| C3 | 载体自洽 | 文档的载体、来源链、元数据或保存条件与声称的创作背景不矛盾（含数字文档） |

### D·拼图汤

| # | 检查项 | 通过条件 |
|---|---|---|
| D1 | 碎片各自诚实 | 每份材料在其自身视角下全部为真，无故意说谎的材料 |
| D2 | 碎片关系唯一合成 | 碎片之间的关系只能合成一个事件真相 |
| D3 | 非单块双义 | 双重含义产生在碎片关系中，不强制每块碎片单独承载双义 |

### E·机制汤

| # | 检查项 | 通过条件 |
|---|---|---|
| E1 | 规则可归纳 | 隐藏规则可通过汤面中的现象模式被归纳，不需要外部知识 |
| E2 | 预测型证据 | 至少一条预测/反例型证据独立于"已用来推演规则本身的异象" |
| E3 | 规则不等价 | 两种不同的隐藏规则不能对汤面中所有现象产生相同的可观察效果 |

## 状态型标签（叠加于 A-E，不独立定级）

状态型不是第六种载体。状态迁移带来的额外推理步骤通过 F2（链条深度）体现，不靠固定加分。

| # | 检查项 |
|---|---|
| S1 | 至少一个状态迁移由玩家行为触发 |
| S2 | 状态迁移改变信息、协议、操作或解释规则中的至少一项 |
| S3 | 状态迁移有可观察痕迹 |
| S4 | 失败模式可收束（卡死时有退路） |
| S5 | 迁移台账在主持人手册中完整记录 |

---

## 导航风险审计表（不参与加分，只定位修缮目标）

以下项目若触发 → 记录为**导航风险**，在修缮诊断中定位回退步骤。**它们不增加难度等级**——难度只由 F1-F4 决定。

| 风险项 | 症状 | 回退步骤 |
|---|---|---|
| 锚点稀疏 | 某拍只有1类锚点类型（物理/行为/时间/文档/关系仅一） | 制汤足迹预检·补锚点 |
| 路径断层 | 两拍之间存在无锚点桥接的跳跃 | 制汤步骤4·重设约束点 |
| 确认门缺失 | 某个关键分叉缺乏收窄搜索空间的是/否问题 | 制汤解题链卡·补确认门 |
| 替代解未排除 | G-竞争解释未通过（存在完整竞争汤底） | 制汤足迹预检或约束点 |

## 难度档映射（试运行阈值 · 校准后锁定）

```
总分 = F1 + F2 + F3 + F4   （范围 4-20）

热场:  4-5     ← 试运行
常规:  6-8     ← 试运行
标准:  9-11    ← 试运行
进阶: 12-14    ← 试运行
深度: 15-20    ← 试运行
```

### 校准流程（12-15锅后锁定）

1. 选12-15锅已完成汤，覆盖 A-E 载体 × 长短 × 各档位
2. 主持者给出独立体感档位（不知道 F1-F4 评分）
3. 运行新盲测协议（≥3次/锅，取中位数）
4. 检查 F1-F4 分档与主持体感是否单调对应
5. 偏差 ≥2 档的案例逐锅分析根因
6. 调整分段阈值，替换"试运行"标记为"已校准"

## 成品标注格式

```
【载体】A·事件汤
【难度构造】进阶（第4档）
【目标阻力】F1=3 F2=2 F3=3 F4=2
【实测难度】进阶（第4档）· 总分=10
【目标偏差】无
【质量闸门】全部通过
```

成汤后填写实测难度。目标偏差 ≥2 档 → 分析根因，决定调整汤还是调整目标。
