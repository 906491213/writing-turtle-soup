# 附录C：速查表

创作过程中逐项勾选，确保不遗漏关键检查。

---

## 创作阶段速查

### 委托卡
- [ ] 情感落点+终点认知句已填
- [ ] 载体+世界规则+内容边界已填
- [ ] 难度构造蓝图已填（F1-F4参数+质量底线+拍数+确认门）
- [ ] 外部知识声明已填（立项闸门2·来源识别已通过）
- [ ] 状态型声明已填（如适用）
- [ ] 预期协议（P0/P1/P2）已选

### 创作核心
- [ ] 胚已去IP化（立项闸门2·来源识别已通过）
- [ ] 按载体构建P和T（A可选信息隔离，B/C/D/E按创作顺序）
- [ ] 约束点定位（载体资格测试通过）
- [ ] P-T咬合完成（不做翻译表）
- [ ] 接缝安全检查（动机/信号来源/格式异常/碎片关系/规则预测，不指向场景异常）
- [ ] 烟雾弹3条件验证（如有）
- [ ] 汤面≤2000字符、汤底≤2000字符
- [ ] 关键句双模型审计（5-8句，按载体分流，全过）

### 变格专用
- [ ] 机制指纹四问全过
- [ ] 机制繁殖测试（≥3条独立物理后果）
- [ ] 机制后果栅栏（概念驱动时强制）

### 解题链卡
- [ ] 入口锚点：接缝类型+首轮方向≥2+入口安全性
- [ ] 拍间发现链：逐拍完整填写
- [ ] 锚点来源三种逐事实填写
- [ ] 可达性审计：每个承重事实有触发源
- [ ] 可导航性审计：每个"答案后新方向"有通向
- [ ] 可证实性审计（机制/状态型）

### 长汤专用（3+拍）
- [ ] 层间证据接力：每拍使用≥1种接力模式
- [ ] 拍间间隙期：每两拍之间≥1个张力锚
- [ ] 波浪型节奏：信息密度非均匀分配
- [ ] 结构收敛：≥2条证据线+收束方式明确

### 状态型专用
- [ ] 状态协议卡四部分全填
- [ ] 可见性：每次迁移有≥1个外部信号
- [ ] 能动性：≥1次迁移由玩家题内行动触发
- [ ] 景观变化：至少一项（信息/协议/操作/解释规则）
- [ ] 失败模式：玩家不触发时有明确收束
