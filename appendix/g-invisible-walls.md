# 附录G：空气墙 — 推理引导与屏障设计

**位置**：约束点定位后的补充工具。解题链卡设计时参考。所有载体适用。

**来源**：空气墙（Invisible Wall）是游戏设计中"视觉可通行但交互被阻"的透明障碍。本附录将该概念迁入海龟汤创作——推理路径上那些"看似可走但走不通"的引导结构。

---

## 一、定义：汤中的空气墙

> 一条玩家自然会被吸引的推理方向，看起来逻辑上可通行，但实际上被汤内事实结构本身阻断——**不是主持人说"不"，是世界的逻辑说"走不通"**。

空气墙不是红鲱鱼（红鲱鱼是假目标，空气墙是**边界**），不是接缝（接缝是入口，空气墙是**围栏**），不是约束点（约束点是P→T的认知鸿沟，空气墙是**玩家在P内自由探索时撞到的自然边界**）。

### 从游戏到汤的映射

| 游戏中的空气墙 | 汤中对应物 |
|------------|---------|
| 悬崖、海洋（自然障碍） | 已确认事实——"尸体在密封房间"→所有"外人作案"推理自动排除 |
| 两侧屏障夹出的窄路（通道） | 汤面细节+早期确认→玩家自然流向接缝方向 |
| 低模远景（假空间） | 看似有意义但实为纹理的细节——增大感知深度 |
| 地图边界透明墙 | 汤的"可问域"边界——超出边界的问题无意义或自消解 |
| 回战场倒计时 | 时间/空间隐性约束——"三天前的来信"隐含了时间线约束 |

## 二、四种汤用空气墙

### 类型1：自然壁（Natural Wall）

**定义**：一个已被玩家确认的汤内事实，其逻辑推论自动封闭一整类推理方向。

**如何运作**：
1. 玩家在自由探索中确认了事实F
2. F的逻辑推论是：方向D不可能
3. 玩家自己得出"D走不通"——不需要主持人说"不"

**示例**：
- "门是从内部锁上的" → 玩家自行排除所有"外部进入"假设
- "死者三天前已经死了" → 玩家自行排除所有"当天作案"时间线
- "A不认识B"（已确认） → 玩家自行排除所有"AB共谋"推理

**设计要点**：
- F必须能被玩家在早期确认（否则壁不存在）
- F→¬D的推论必须足够短（一步逻辑，不需要跳两步以上）
- D必须是被封堵后玩家还剩至少一个可行方向（否则是死胡同，不是通道）

**失败模式**：
- F未被玩家确认 → 壁是虚的，玩家在虚无中乱撞
- F→¬D推论太长 → 玩家意识不到壁存在，继续浪费时间
- 封堵后无路 → 全封＝玩家穷举

### 类型2：引导栅（Guide Fence）

**定义**：玩家在自然探索时不会被吸引的方向——不是走不过去，是**根本没人往那走**。

**如何运作**：
- 汤面的叙事框架 + 早期确认 → 创造的"重力"让玩家注意力自然流向接缝
- 栅外的推理方向在逻辑上成立，但汤面没有给出任何去那里的锚

**示例**：
- 汤面以第一人称写就，"我"的视角天然排除了"这是多人合谋的叙事诡计"
- 汤面明确发生在"一个小时内"，所有跨时间线的推理方向缺乏锚点

**设计要点**：
- 栅必须"无感"——玩家撞不到栅才叫好栅
- 栅不能是"因为有栅所以不让你去"——必须是"汤面本身就没给你去那里的理由"
- 与自然壁的区别：自然壁 = 去了撞回来；引导栅 = 根本不会去

**失败模式**：
- 栅太明显 → 玩家意识到被引导 → 逆反心理 → 偏要去栅外
- 栅封错了方向 → 把可能的接缝方向也封了

### 类型3：远景带（Vista Zone）

**定义**：汤面中刻意保留的、看起来有意义但不在关键路径上的细节或人物。

**如何运作**：
- 这些细节制造了"世界比谜题大"的错觉
- 它们有诚实的解释（就像远景的山确实存在），但追到底不抵达核心真相
- 与红鲱鱼的区别：红鲱鱼主动吸引并消耗追问；远景带安静地待着，玩家可能注意到也可能忽略

**示例**：
- 汤面提到"桌上有一杯没喝完的咖啡"——暗示有人匆忙离开，但人物匆忙的原因与核心真相无关
- "窗外有鸟叫声"——诚实的感官细节，不承载加密

**设计要点**：
- 远景细节必须诚实在场——不能是"其实没有咖啡"
- 追2-3问应有诚实回答——但不能打开新推理方向
- 远景带是沉浸感的来源，不是加密工具

**失败模式**：
- 远景细节太多 → 玩家分不清承重与纹理
- 远景被玩家误当接缝 → 大量时间浪费在无关方向

### 类型4：回弹壁（Bounce Wall）

**定义**：一个问题的诚实回答，其逻辑推论自然将玩家弹回接缝方向。

**如何运作**：
1. 玩家提出方向性试探问题Q
2. 主持人诚实回答"是"或"不是"
3. 该回答的逻辑推论让玩家自行意识到：Q指向的方向不成立，应该换个方向

**示例**：
- 玩家："凶手是从窗户进来的吗？" → 主持："不是" → 玩家推论：从门进来的，或本来就在屋内
- 玩家："这是自杀吗？" → 主持："不是" → 玩家推论：他杀，进入他杀方向的推理

**设计要点**：
- 回弹壁的问题必须"答完后玩家还剩至少两个方向"——只剩一个方向 = 穷举
- 回答的推论方向必须有汤面锚点支撑——不能只靠"不是"就指望玩家弹到正确方向
- B类汤中"是不是XX"→"不是"这类回弹，常需要补一句事实锚点防止玩家飘走

**失败模式**：
- 弹回后玩家找不到新方向 → 回弹壁变死胡同
- 连续多个回弹 → 玩家感觉在被主持人"赶"

## 三、好空气墙 vs 坏空气墙

### 好空气墙（融入世界逻辑）

- 壁由已确认事实的自然推论构成——不是主持人替你挡
- 玩家撞到壁时，能说出"因为X，所以Y不可能"
- 壁不要求玩家持有外部知识
- 壁封堵了一个方向，但同时暗示（或至少不阻碍）另一个方向存在

### 坏空气墙（世界逻辑与交互断裂）

| 坏空气墙类型 | 表现 | 游戏类比 | 根本原因 |
|-----------|------|---------|--------|
| **主持人挡箭牌** | 玩家问的方向是合理的，但主持人只能说"不重要"或回避 | 开着的大门走不进去 | 壁不在事实层面——在主持人的嘴层面 |
| **隐形天花板** | 玩家的推理在正确轨道上，但缺乏确认手段 | 跳到一半撞到透明屋顶 | L1足迹缺失——变量无锚点 |
| **假开放世界** | 汤面暗示了某个大方向，追进去全是"不是"/"不重要" | GTA早期的海域透明墙 | 远景带误标为可探索区域——红鲱鱼不当设计 |
| **断头路** | 壁封堵后，玩家无路可走 | 掉出地图 | 接缝方向被封——设计时只堵不疏 |

## 四、设计原则

### 原则1：壁在事实中，不在回答中

```
✗ "这件事不重要" — 壁在主持人的回避里
✓ "门是锁着的" → 玩家推论：外人无法进入 — 壁在已确认事实的逻辑推论里
```

### 原则2：每堵一壁，留一扇窗

每道自然壁封堵一个方向的同时，至少还剩下两个可行动的方向。这道规则是解题链"零外部知识"的延伸——壁不是用来清场的，是用来收窄的。

### 原则3：壁必须可发现

自然壁上承重的那个事实F，必须能在汤面或早期确认中被玩家触及。如果F需要玩家问到"正确的问题"才能浮现 → 壁不存在。

### 原则4：远景不骗人

远景带的细节如果被玩家盯上追问——每个追问方向在2-3问内给出诚实的、不指向核心真相的答案。远景带不是"假信息"，是"真但不承重的信息"。

## 五、空气墙审计清单

在解题链卡设计完成后，逐项审计：

- [ ] 每个拍间，玩家有没有至少一个自然壁引导方向收窄？
- [ ] 有没有主持人"不重要"出现的地方？→ 检查是否可替换为自然壁（补一个事实让玩家自行放弃该方向）
- [ ] 汤面中有没有暗示大方向但追进去全是死路的"假开放世界"？
- [ ] 接缝方向有没有被某道壁意外封堵？
- [ ] 远景带是否诚实？（追2-3问仍有诚实回答）
- [ ] 连续回弹壁是否超过2个？（超过 → 解题链可能需要重新设计）
- [ ] 最后一道壁封堵后，玩家是否还有一个明确的、有锚点的方向？

## 六、与其他概念的边界

| 概念 | 定义 | 与空气墙的关系 |
|------|------|-------------|
| **接缝** | 玩家读完汤面后最先问的问题（P→T的入口） | 空气墙围出通往接缝的路径 |
| **约束点** | P和T之间的认知鸿沟（接缝指向的具体位置） | 空气墙是P内的导航系统，约束点是P→T的跨越点 |
| **红鲱鱼** | 比真相更显眼的假目标（主动吸引） | 空气墙是被动边界，红鲱鱼是主动诱饵 |
| **烟雾弹** | 经得起追问但不通核心真相的"余细节" | 远景带是烟雾弹的天然来源 |
| **锚点** | 汤面中可被独立提问的事实 | 自然壁的承重事实必须已被锚定 |
