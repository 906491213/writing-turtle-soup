# 附录G：空气墙与隐藏通道 — 推理空间拓扑设计

**位置**：约束点定位后的补充工具。解题链卡设计时参考。所有载体适用。

**级别**：次线——立项闸门3+制汤约束点定位时参考，非必读。

**来源**：空气墙（Invisible Wall）和隐藏通道（Hidden Passage）是游戏关卡设计的一对镜像概念——前者"看得见走不通"，后者"看不见走得通"。本附录将这对概念迁入海龟汤创作，用于设计玩家在P内的推理空间拓扑。

---

## 一、定义：汤中的空气墙

> 一条玩家自然会被吸引的推理方向，看起来逻辑上可通行，但实际上被汤内事实结构本身阻断——**不是主持人说"不"，是世界的逻辑说"走不通"**。

空气墙不是红鲱鱼（红鲱鱼是假目标，空气墙是**边界**），不是接缝（接缝是入口，空气墙是**围栏**），不是约束点（约束点是P→T的认知鸿沟，空气墙是**玩家在P内自由探索时撞到的自然边界**）。

### 从游戏到汤的映射

| 游戏中的空气墙 | 汤中对应物 |
|------------|---------|
| 悬崖、海洋（自然障碍） | 已确认事实——"尸体在密封房间"→所有"外人作案"推理自动排除 |
| 两侧屏障夹出的窄路（通道） | 汤面细节+早期确认→玩家自然流向接缝方向 |
| 低模远景（假空间） | 看似有意义但实为纹理的细节——增大感知深度 |
| 地图边界透明墙 | 汤的"可问域"边界——超出边界的问题无意义或自消解 |
| 回战场倒计时 | 时间/空间隐性约束——"三天前的来信"隐含了时间线约束 |

## 二、四种汤用空气墙

### 类型1：自然壁（Natural Wall）

**定义**：一个已被玩家确认的汤内事实，其逻辑推论自动封闭一整类推理方向。

**如何运作**：
1. 玩家在自由探索中确认了事实F
2. F的逻辑推论是：方向D不可能
3. 玩家自己得出"D走不通"——不需要主持人说"不"

**示例**：
- "门是从内部锁上的" → 玩家自行排除所有"外部进入"假设
- "死者三天前已经死了" → 玩家自行排除所有"当天作案"时间线
- "A不认识B"（已确认） → 玩家自行排除所有"AB共谋"推理

**设计要点**：
- F必须能被玩家在早期确认（否则壁不存在）
- F→¬D的推论必须足够短（一步逻辑，不需要跳两步以上）
- D必须是被封堵后玩家还剩至少一个可行方向（否则是死胡同，不是通道）

**失败模式**：
- F未被玩家确认 → 壁是虚的，玩家在虚无中乱撞
- F→¬D推论太长 → 玩家意识不到壁存在，继续浪费时间
- 封堵后无路 → 全封＝玩家穷举

### 类型2：引导栅（Guide Fence）

**定义**：玩家在自然探索时不会被吸引的方向——不是走不过去，是**根本没人往那走**。

**如何运作**：
- 汤面的叙事框架 + 早期确认 → 创造的"重力"让玩家注意力自然流向接缝
- 栅外的推理方向在逻辑上成立，但汤面没有给出任何去那里的锚

**示例**：
- 汤面以第一人称写就，"我"的视角天然排除了"这是多人合谋的叙事诡计"
- 汤面明确发生在"一个小时内"，所有跨时间线的推理方向缺乏锚点

**设计要点**：
- 栅必须"无感"——玩家撞不到栅才叫好栅
- 栅不能是"因为有栅所以不让你去"——必须是"汤面本身就没给你去那里的理由"
- 与自然壁的区别：自然壁 = 去了撞回来；引导栅 = 根本不会去

**失败模式**：
- 栅太明显 → 玩家意识到被引导 → 逆反心理 → 偏要去栅外
- 栅封错了方向 → 把可能的接缝方向也封了

### 类型3：远景带（Vista Zone）

**定义**：汤面中刻意保留的、看起来有意义但不在关键路径上的细节或人物。

**如何运作**：
- 这些细节制造了"世界比谜题大"的错觉
- 它们有诚实的解释（就像远景的山确实存在），但追到底不抵达核心真相
- 与红鲱鱼的区别：红鲱鱼主动吸引并消耗追问；远景带安静地待着，玩家可能注意到也可能忽略

**示例**：
- 汤面提到"桌上有一杯没喝完的咖啡"——暗示有人匆忙离开，但人物匆忙的原因与核心真相无关
- "窗外有鸟叫声"——诚实的感官细节，不承载加密

**设计要点**：
- 远景细节必须诚实在场——不能是"其实没有咖啡"
- 追2-3问应有诚实回答——但不能打开新推理方向
- 远景带是沉浸感的来源，不是加密工具

**失败模式**：
- 远景细节太多 → 玩家分不清承重与纹理
- 远景被玩家误当接缝 → 大量时间浪费在无关方向

### 类型4：回弹壁（Bounce Wall）

**定义**：一个问题的诚实回答，其逻辑推论自然将玩家弹回接缝方向。

**如何运作**：
1. 玩家提出方向性试探问题Q
2. 主持人诚实回答"是"或"不是"
3. 该回答的逻辑推论让玩家自行意识到：Q指向的方向不成立，应该换个方向

**示例**：
- 玩家："凶手是从窗户进来的吗？" → 主持："不是" → 玩家推论：从门进来的，或本来就在屋内
- 玩家："这是自杀吗？" → 主持："不是" → 玩家推论：他杀，进入他杀方向的推理

**设计要点**：
- 回弹壁的问题必须"答完后玩家还剩至少两个方向"——只剩一个方向 = 穷举
- 回答的推论方向必须有汤面锚点支撑——不能只靠"不是"就指望玩家弹到正确方向
- B类汤中"是不是XX"→"不是"这类回弹，常需要补一句事实锚点防止玩家飘走

**失败模式**：
- 弹回后玩家找不到新方向 → 回弹壁变死胡同
- 连续多个回弹 → 玩家感觉在被主持人"赶"

## 三、好空气墙 vs 坏空气墙

### 好空气墙（融入世界逻辑）

- 壁由已确认事实的自然推论构成——不是主持人替你挡
- 玩家撞到壁时，能说出"因为X，所以Y不可能"
- 壁不要求玩家持有外部知识
- 壁封堵了一个方向，但同时暗示（或至少不阻碍）另一个方向存在

### 坏空气墙（世界逻辑与交互断裂）

| 坏空气墙类型 | 表现 | 游戏类比 | 根本原因 |
|-----------|------|---------|--------|
| **主持人挡箭牌** | 玩家问的方向是合理的，但主持人只能说"不重要"或回避 | 开着的大门走不进去 | 壁不在事实层面——在主持人的嘴层面 |
| **隐形天花板** | 玩家的推理在正确轨道上，但缺乏确认手段 | 跳到一半撞到透明屋顶 | L1足迹缺失——变量无锚点 |
| **假开放世界** | 汤面暗示了某个大方向，追进去全是"不是"/"不重要" | GTA早期的海域透明墙 | 远景带误标为可探索区域——红鲱鱼不当设计 |
| **断头路** | 壁封堵后，玩家无路可走 | 掉出地图 | 接缝方向被封——设计时只堵不疏 |

---

## 四、设计原则

### 原则1：壁在事实中，不在回答中

```
✗ "这件事不重要" — 壁在主持人的回避里
✓ "门是锁着的" → 玩家推论：外人无法进入 — 壁在已确认事实的逻辑推论里
```

### 原则2：每堵一壁，留一扇窗

每道自然壁封堵一个方向的同时，至少还剩下两个可行动的方向。这道规则是解题链"零外部知识"的延伸——壁不是用来清场的，是用来收窄的。

### 原则3：壁必须可发现

自然壁上承重的那个事实F，必须能在汤面或早期确认中被玩家触及。如果F需要玩家问到"正确的问题"才能浮现 → 壁不存在。

### 原则4：远景不骗人

远景带的细节如果被玩家盯上追问——每个追问方向在2-3问内给出诚实的、不指向核心真相的答案。远景带不是"假信息"，是"真但不承重的信息"。

## 五、空气墙审计清单

在解题链卡设计完成后，逐项审计：

- [ ] 每个拍间，玩家有没有至少一个自然壁引导方向收窄？
- [ ] 有没有主持人"不重要"出现的地方？→ 检查是否可替换为自然壁（补一个事实让玩家自行放弃该方向）
- [ ] 汤面中有没有暗示大方向但追进去全是死路的"假开放世界"？
- [ ] 接缝方向有没有被某道壁意外封堵？
- [ ] 远景带是否诚实？（追2-3问仍有诚实回答）
- [ ] 连续回弹壁是否超过2个？（超过 → 解题链可能需要重新设计）
- [ ] 最后一道壁封堵后，玩家是否还有一个明确的、有锚点的方向？

## 六、与其他概念的边界

| 概念 | 定义 | 与空气墙的关系 |
|------|------|-------------|
| **接缝** | 玩家读完汤面后最先问的问题（P→T的入口） | 空气墙围出通往接缝的路径 |
| **约束点** | P和T之间的认知鸿沟（接缝指向的具体位置） | 空气墙是P内的导航系统，约束点是P→T的跨越点 |
| **红鲱鱼** | 比真相更显眼的假目标（主动吸引） | 空气墙是被动边界，红鲱鱼是主动诱饵 |
| **烟雾弹** | 经得起追问但不通核心真相的"余细节" | 远景带是烟雾弹的天然来源 |
| **锚点** | 汤面中可被独立提问的事实 | 自然壁的承重事实必须已被锚定 |

## 七、隐藏通道（Hidden Passage）

### 对称关系

```
空气墙：看得见，走不通 — 表层暗示"能走"，实际被事实结构阻断
隐藏通道：看不见，走得通 — 表层暗示"不能走"，实际通向真相
```

空气墙是P内的导航系统，引导玩家远离错误方向。隐藏通道是P内的**反直觉入口**——玩家自行放弃的某条路径，恰恰是通往T的必经之路。

### 游戏侧溯源

| 游戏中的隐藏通道 | 经典实例 |
|------------|---------|
| **假墙（Illusion Wall）** | 黑魂系列——砍一刀才会消失的墙壁；DOOM——走进看似实心墙面的隐藏房间 |
| **可破坏障碍** | 塞尔达——炸弹炸开有裂纹的墙；暗黑破坏神——隐藏的碎石堆后是地牢入口 |
| **瀑布后面** | 几乎所有RPG——瀑布="这里有隐藏通道"的通用语言 |
| **无提示的交互点** | 马力欧——跳进看似背景的管道；传送门——看似装饰的墙面能开传送门 |
| **信息触发型** | 银河战士——知道某个机制后才意识到"那面墙可以打开" |

### 汤中映射

隐藏通道的核心结构：**玩家持有某个表层假设H，H让方向D看起来不可能，于是玩家不去D。但H是错的。当H被推翻，D突然变成唯一的或关键的通路。**

### 四种汤用隐藏通道

#### 类型1：假壁（False Wall）

**定义**：一条推理路径，被汤面中的表面事实"自然排除"，但该事实基于一个玩家尚未意识到的隐藏假设。

**如何运作**：
1. 汤面或早期确认给出了事实F
2. F在常规理解下 → 排除了方向D
3. 但F的常规理解依赖于隐藏假设H
4. 当H被推翻，D突然开放

**示例**：
- "房间是密室" → 玩家自然排除"有人进出"。但隐藏假设是"锁=不可从外部操作"。——假壁在"锁"的物理性质上。
- "A有不在场证明" → 玩家排除A是当事人。但隐藏假设是"不在场证明=人不在场"。——假壁在"证明"的可靠性上。

**设计要点**：
- 假壁不能是"主持人骗人"——F本身必须是诚实的。隐藏的不是F的真假，是F的理解框架。
- 推翻H的线索必须在汤面中有锚点——不能是玩家瞎猜到的。
- 假壁只在H被推翻后才"消失"——在此之前它确实是一道有效的壁。

**失败模式**：
- H太薄（玩家第一轮就想到） → 假壁不存在
- H太厚（推翻H的线索缺失） → 假壁 = 永远封死的路
- F本身是假的 → 不是假壁，是汤面撒谎——犯规

#### 类型2：暗门（Secret Door）

**定义**：一条推理路径，只有当玩家先发现了变量V，这条路径才变得可见。在此之前，它不在玩家的注意范围内——不是被封堵，是根本不被感知。

**如何运作**：
1. 汤面中存在细节X，在无辜框架下无意义（或意味完全不同）
2. 玩家发现了变量V（来自另一条推理线）
3. V被确认后，X突然承载了新的意义 → 打开了一条之前不存在（不被感知）的推理方向

**与假壁的区别**：假壁 = 方向能看见但被挡；暗门 = 方向完全不在视野中。

**示例**：
- 汤面提到"A每周三都去同一个地方"——无辜框架下 = 生活习惯。当玩家发现B住在那个地方附近 → 暗门打开：A在秘密见B。
- 汤面中一句看似寒暄的对话，在知道某个人物关系后变成关键证词。

**设计要点**：
- X必须诚实地存在于汤面中——不能是"其实汤面没提但主持人暗示有"
- X在无辜框架下必须有合理存在理由（否则会被玩家盯上 → 变成接缝而非暗门）
- V→X的连接必须足够短，玩家发现V后能自行回溯到X

**失败模式**：
- X在无辜框架下无存在理由 → 玩家会提前盯上X，暗门不再"暗"
- V→X连接过长 → 玩家发现V后想不到回溯X

#### 类型3：倒转路径（Reversal Path）

**定义**：表层框架下某方向看似荒谬或逻辑不通，但框架本身的倒转使该方向成为唯一可能。

**如何运作**：
1. 方向D在表层框架下明显不成立——玩家甚至不会问
2. 随着发现链推进，支撑表层框架的某个支柱信念被推翻
3. 框架倒转后，D成为唯一的、或最佳的推理方向

**与假壁的区别**：假壁 = 一道具体的墙，由某个隐藏假设撑住；倒转路径 = 整个框架旋转后，之前所有"不可能"的方向重新洗牌。

**示例**：
- "不可能自杀，因为没找到凶器" → 当玩家发现凶器存在但被藏匿 → 自杀突然可能了
- 表层框架"这是一起意外"排除所有犯罪方向 → 框架倒转为"这是谋杀"后，所有犯罪方向开放

**设计要点**：
- 倒转路径通常出现在多拍汤的中后段——作为框架推翻后的"奖励路径"
- 不能只推翻框架不给新方向——框架倒了，玩家需要有锚点知道往哪走
- 倒转后开放的路径应该在汤面中已有可回溯的痕迹

**失败模式**：
- 框架推翻后的方向太多 → 玩家从被堵变成迷路
- 倒转后的路径缺乏回溯锚点 → "那现在怎么办？"

#### 类型4：必经窄口（Choke Point）

**定义**：多条推理线收敛到同一个不可绕过的发现——一个隐藏通道，一旦走过，回看整个汤都变了。

**如何运作**：
- 不管玩家从哪个方向切入，最终都必须穿过这个窄口
- 窄口在穿过前不可见（或看起来无关紧要）
- 穿过后，之前分散的碎片突然拼合

**与暗门的区别**：暗门是可选的路径之一；必经窄口是拓扑上的必经点。

**示例**：
- 玩家可能从时间线、人际关系、物证三个方向切入，但三条线都指向同一个事实X——没确认X之前碎片散落，确认X后全景浮现
- 塔台汤中的"装置用途"——不管玩家从哪条推理线走，最终必须理解装置的以命换命机制

**设计要点**：
- 窄口的发现条件必须可被多条独立路径抵达——不能是"只有一种方式能发现"
- 窄口穿过后的体验必须是"原来如此"而非"就这？"
- 窄口是解题链卡上的核心节点

**失败模式**：
- 只有一条路通向窄口 → 玩家可能永远找不到
- 窄口穿过后不改变任何认知 → 不是窄口，是附注

## 八、空气墙与隐藏通道的联合运用

一锅好汤的P内拓扑 = 空气墙收窄可能性空间 × 隐藏通道提供突破点。

```
空气墙：──────┬──────┬──────  ← 这些方向走不通（自然壁/回弹壁）
              │      │
         玩家注意力的"峡谷"  ← 引导栅夹出的路径
              │      │
      ───────┼──────┼──────  ← 隐藏通道：看似也走不通，但这里有道假壁
              │      │
          接缝方向  ← 大多数玩家会从这里进入
              │
         必经窄口  ← 不管从哪进，最终都要穿过这里
```

### 联合设计原则

- **不双堵**：空气墙和隐藏通道不对同一个方向生效——要么可见可堵（气），要么不可见可通过（隐）
- **隐后必通**：隐藏通道被穿过后的方向，应该有明确的锚点支撑继续前行——暗门后面得有路，不能是另一道门
- **气隐互补**：一堵自然的空气墙（自然壁），旁边经常就该有一条隐藏通道——"正面走不通"暗示"侧面可能有入口"
