# 附录A：BVT良性来源四项

幽默/黑色幽默汤在设计"笑"的落点时，可逐项检视良性（benign）是否成立。不是每题都要全过——黑色幽默的目标可能就是"笑与不安共存"——四项供排查薄弱点：

1. **实际伤害被控制或不存在？** 汤底中是否有真实受害者？如果有，受害是否被叙事距离或荒诞框架缓冲？

2. **角色是否有主动性？** 关键角色是能动者还是纯粹受害者？能动者更容易让玩家在笑中保留共情。

3. **是否有足够的荒诞距离？** 事件离玩家日常生活有多远？距离越远，良性越容易成立。

4. **玩家为何不会把它读成纯粹残酷？** 如果删掉所有荒诞元素，剩下的核心事件是否本身就是一个悲剧？如果是 → 汤面需要更明确的良性信号。
