# 海龟汤创作方法论

一套完整的海龟汤（情境猜谜 / lateral thinking puzzle）**创作框架**——从灵感到成品，每一步都有闸门。

## 这是什么

海龟汤不是把完整故事藏起来让玩家猜；它是让玩家沿**题内证据、已确认事实与可观察反馈**，逐步替换自己的错误框架，最终抵达唯一真相。

这套方法论解决的核心问题：**如何设计一锅"玩家能靠推理走出去、而不是靠主持人放水"的汤。**

## 四阶段流水线

| 阶段 | 做什么 | 谁主导 |
|------|--------|--------|
| **一、立项** | 这个胚值得做吗？七道资格闸门 | 你和 AI 协作 |
| **二、制汤** | 从胚长成完整的汤（P/T 模型→变量→解题链→汤面汤底→主持人手册） | AI 独立施工 |
| **三、复验** | 成品有没有漏底？玩家能不能靠推理走出去？ | AI 独立核验 |
| **四、修复或回炉** | 反馈来了——局部修还是退回立项重来？ | 你和 AI 协作 |

## 核心原则

- **原子双读**：同一个情境，无辜读法下完全透明，汤底读法下完全成立
- **零外部知识**：每个承重事实都必须在题内有触发源
- **推理落脚点**：玩家是靠推理排除旧信念，而非靠主持人说"不是"
- **诚实回答**：主持人不能用回避来维持难度

## 适用范围

适用于各类海龟汤：事件汤、感官汤、文档汤、拼图汤、机制汤，及其组合。覆盖单拍到多层长篇。
